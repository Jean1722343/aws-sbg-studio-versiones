# AWS SBG Studio · versiones

La app del **AWS Student Builder Group UNISTMO** para hacer posts, historias, carruseles,
portadas y certificados con la línea gráfica oficial de AWS.

Aquí solo se publican las versiones (el código es privado). **La app se actualiza sola** desde
aquí: cuando sale una versión nueva aparece un aviso y con un toque se instala. Actualizar
nunca borra tus diseños, fuentes ni la conexión al Drive del equipo.

## Descargar

👉 **[Última versión](https://github.com/Jean1722343/aws-sbg-studio-versiones/releases/latest)** — en «Assets»:

| Equipo | Archivo |
|---|---|
| Android (casi todos los celulares) | `AWS-SBG-Studio-android-arm64.apk` |
| Android viejo (si el anterior dice «no compatible») | `AWS-SBG-Studio-android-armv7.apk` |
| Windows 10 / 11 | `AWS-SBG-Studio-windows-instalador.exe` |
| Windows sin instalar | `AWS-SBG-Studio-windows-x64.zip` |
| Linux x64 | `AWS-SBG-Studio-linux-x64.tar.gz` |

## Instalar

**Android**: abre el APK. Android pedirá permiso para «instalar apps de origen desconocido»
(a tu navegador o a Drive): acéptalo solo para esto. Las siguientes versiones las instala la
propia app (te pedirá ese permiso una vez para ella).

**Windows**: abre el instalador. Si aparece «Windows protegió tu PC»: *Más información* →
*Ejecutar de todas formas* (la app es del grupo y no está firmada). No pide administrador.

**Linux**:
```bash
tar xzf AWS-SBG-Studio-linux-x64.tar.gz
./AWS-SBG-Studio/instalar.sh
```
Queda en el menú de aplicaciones y como comando `aws-sbg-studio`.

## Unirte al Drive del equipo

Pídele la invitación a Jean Paul (un texto que empieza con `awssbg:`). En la app: pestaña
**Equipo** → **Me invitaron** → **Pegar la invitación** → tu nombre.
